In my GovtGuru app, the Progress page (/progress) has a 
"Quiz Performance by Subject" panel that shows progress 
bars with percentages but the subject NAMES are not 
displaying — they appear blank/empty above each bar.

Please fix this issue by doing the following:

STEP 1 — Find the Progress page component
Look for the file that renders "Quiz Performance by Subject" 
section. It could be in:
- app/progress/page.jsx
- pages/progress.jsx  
- components/Progress.jsx
- components/ProgressPage.jsx

STEP 2 — Find how subject data is being fetched
The component is likely querying either:
- question_attempts table (which has examCode, subjectCode columns)
- quiz_attempts table
- subjects table

STEP 3 — Identify the bug
The subject name is probably missing because:

Possibility A: The query fetches subjectCode (like "QA", "ENG") 
but the display code tries to show subject_name which is 
undefined/null

Possibility B: The join with subjects table is failing or 
subjects table does not have data yet

Possibility C: The field name mismatch — database has 
"subjectCode" but code looks for "subject_code" (camelCase 
vs snake_case mismatch)

STEP 4 — Fix the subject name display using this approach:

First try to join with the subjects table:
const { data } = await supabase
  .from('question_attempts')
  .select('subjectCode, is_correct, subjects!inner(subject_name)')
  .eq('user_id', userId)

to convert subject codes to readable names, and apply it 
wherever subject names are displayed:
