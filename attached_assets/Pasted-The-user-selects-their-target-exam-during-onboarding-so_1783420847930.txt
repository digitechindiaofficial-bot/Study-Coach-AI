The user selects their target exam during onboarding, so the syllabus should be personalized.

Update the syllabus system with the following rules:

1. Every user should only see the syllabus of their selected exam.
2. Do not load or display syllabus of any other exam.
3. The syllabus page should automatically fetch data using the user's selected_exam.
4. The admin can still import all exam syllabi, but users only access their own exam.

Syllabus Structure

Exam
    ├── Subject
    │      ├── Topic

No subtopics are required.

Each topic should support:
- AI Notes
- Quiz
- PYQs
- Practice Questions
- Revision
- Mark Complete

Each exam should contain its complete official syllabus.

Supported Exams:

- SSC CGL
- SSC CHSL
- IBPS PO
- IBPS Clerk
- SBI PO
- RRB NTPC
- UPPSC
- BPSC
